# ABYSS — 深淵

A samurai roguelite that runs entirely in the browser. Descend into the cursed depths, slay the three demon lords, and seal the Abyss.

## Play

Open `index.html` in any modern browser — no build step or install needed. Best in landscape on mobile.

To play online, enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root). The game will then be at `https://zach78841-cmyk.github.io/Abyss/`.

## Controls

- **Mobile:** touch the left half to move · 斬 slash · 避 dodge · 技 skill
- **Keyboard:** WASD / arrows to move · J / Space or left click to slash · K / Shift to dodge · L / E for skill · Esc / P to pause

## Features

- 3 floors, each with a demon-lord boss and mini-bosses
- 4 weapons, relics, cursed altars and the Tanuki shop
- Combo system, perfect dodges and counters
- Shiny monster collection with unlockable skins
- Achievements, difficulty levels and save export/import
